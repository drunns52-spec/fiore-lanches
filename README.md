# Fiore Lanches — Etapa 4

Logo oficial fornecida pelo cliente incorporada ao aplicativo (assets/images/logo_oficial.png). Tela de abertura Flutter e imagem de ícone Android preparadas. A integração de carrinho, entrega e WhatsApp permanece da Etapa 3.

## Gerar o APK no computador com Flutter e Android SDK

```bash
flutter create . --platforms android
flutter pub get
dart run flutter_launcher_icons
flutter analyze
flutter build apk --release
```

O APK estará em `build/app/outputs/flutter-apk/app-release.apk`.

**Atenção:** Não foi possível compilar nem testar neste ambiente porque Flutter/Android SDK não estão instalados. O ZIP é código-fonte, não APK.
